# Published result tables

These compact files are public copies of the final `ceus_v3` outputs used by
the manuscript. Workstation-specific path prefixes were replaced with
repository-relative paths; numerical results were not changed.

| File | Contents |
|---|---|
| `graph_inventory.csv` | Endpoint, L-space, and P-space graph inventory |
| `endpoint_route_quality_audit.csv` | Route continuity and construction audit |
| `stop_sequence_quality_audit.csv` | Ordered-stop sequence audit |
| `master_results.csv` | Main Endpoint result for each city–algorithm pair |
| `representation_pairwise_summary.csv` | Endpoint/L/P agreement metrics |
| `lp_stop_threshold_scan.csv` | L/P results for 50–150 m stop grouping |
| `threshold_sensitivity_*.csv` | Endpoint stop-annotation audit |
| `matched_granularity_results.csv` | Predeclared matched-community-count results |
| `spatial_compactness_*.csv` | Compactness and contiguity diagnostics |
| `metric_pairwise_correlation_summary_filtered.csv` | Metric dependence |
| `scale_sensitivity_correlation_summary_filtered.csv` | Exploratory scale relations |
| `poi_master.csv` | POI functional summaries |
| `poi_null_model_tests.csv` | Global and spatial-block POI null models |
| `poi_community_profiles.csv` | Selected community functional profiles |
| `boundary_documentation_filtered.csv` | Study-boundary documentation |

Large community membership files, graph checkpoints, interactive HTML maps,
and publication figures are excluded from this GitHub-ready directory. They
should be deposited in an archival data repository if full bit-for-bit result
reproduction is required.
